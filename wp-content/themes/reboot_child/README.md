# Reboot Child

Дочерняя тема личного сайта [rosnavigation.ru](https://rosnavigation.ru). Родитель — Reboot 1.5.4, каталог `reboot`. Активной должна оставаться **Reboot Child**.

Нужны WordPress 6.4+ и PHP 8.2+. Сейчас тема проверена на WordPress 7.1 и PHP 8.2+. Версия темы указана в `style.css`.

## Что заливать

На сервер попадает только каталог `wp-content/themes/reboot_child`, целиком, поверх уже стоящей дочерней темы.

Не заливать и не править:

- родительскую тему `wp-content/themes/reboot`
- ядро WordPress
- `wp-config.php` и `.htaccess`
- плагины

В `functions.php` блок с пометкой «НЕ УДАЛЯЙТЕ ДАННЫЙ КОД» оставлять как есть. Ниже него можно добавлять свой код.

Шапка и подвал живут в родителе. Их файлы не копируются в дочернюю тему.

## Обновление

1. Скачать свежий каталог `reboot_child` из репозитория.
2. Заменить им каталог на сервере. Родителя не трогать.
3. Открыть главную в браузере без кэша.

Стили подключаются с меткой времени файла, отдельный сброс кэша темы не нужен. Если открыта старая вёрстка, обновите страницу с обходом кэша браузера.

Родителя можно обновлять отдельно. После его обновления проверьте главную, одну запись и страницу контактов: дочерняя тема не подменяет `header.php` и `footer.php`.

Повторная заливка не переписывает тексты страниц, меню и настройки чтения. Запись «Привет, мир!», страница «Пример страницы» и черновик «Политика конфиденциальности» этой темой не удаляются.

## Что тема делает один раз

При первом заходе, и только если этого ещё нет:

- страницы `resume`, `blog`, `contact`, если такого ярлыка нет;
- если в «Настройки → Чтение» всё ещё стоят последние записи: страница «Главная», она становится статической главной, а `/blog/` — лентой записей;
- если область меню «header» пустая: меню «Основное меню» с пунктами Главная, Резюме, Блог, Контакты. Пустой подвал получает то же меню.

Уже назначенное меню шапки не заменяется. Уже выбранная статическая главная не переключается заново.

Плагины тема не ставит. Поля резюме — обычные метабоксы, не ACF.

## Где править содержание

- **Внешний вид → Настроить → Сайт-резюме** — первый экран, три факта, подписи блоков, краткое «о себе», образование, контакты, фото и PDF. Пока поле «Фото» пустое, главная и страница резюме показывают портрет из `assets/images/portrait.jpg`. Выбранное в настройщике фото заменяет его.
- **Записи → Опыт** и **Записи → Проекты** — шкала и карточки. Пустой блок на сайте не показывается.
- **Навыки** — группы и навыки внутри групп.
- Страница контактов показывает шорткод `[contactform]` родителя.

Пустое сохранённое поле в настройщике скрывает фразу. Пока поле ни разу не сохраняли, тема подставляет короткие подписи вроде «Статьи» и «Резюме».

## Проверка после заливки

- [ ] `/` — лендинг без сайдбара, один заголовок `h1`, справа или под текстом портрет.
- [ ] `/resume/` — тот же портрет круглым кадром рядом с заголовком.
- [ ] Вкладка главной содержит роль, не только название сайта.
- [ ] В исходном коде есть `meta name="description"` и `og:title`.
- [ ] `/resume/` на всю ширину, без комментариев. Пустые опыт, навыки, образование и PDF не занимают место.
- [ ] `/blog/` — лента записей и сайдбар родителя.
- [ ] `/contact/` — форма Reboot, комментарии закрыты.
- [ ] Меню шапки: Главная, Резюме, Блог, Контакты.
- [ ] В админке есть Опыт, Проекты и Навыки.
- [ ] Узкое окно около 320px и широкий экран: колонка не прилипает к краям и не растягивается на всю ширину 2560px.
- [ ] Тёмная схема системы: текст читается, шапка остаётся тёмной.
- [ ] При «уменьшать движение» в системе блоки видны сразу. При обычном движении карточка чуть приподнимается от наведения, сверху тонкая полоска прокрутки.
- [ ] Запись «Привет, мир!», «Пример страницы» и черновик политики на месте.
