# РосНавигация

Сайт на WordPress. В репозитории дочерняя тема Reboot: `wp-content/themes/reboot_child`.

Как заливать обновление и что проверить после заливки: [wp-content/themes/reboot_child/README.md](wp-content/themes/reboot_child/README.md).

Родительскую тему `reboot`, ядро, `wp-config.php`, `.htaccess` и плагины этот каталог не заменяет.
